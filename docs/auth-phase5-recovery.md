# Phase 5: device return and controlled test accounts

App updates preserve the Android Keystore-backed session; the server rotates its token and observes the expiry window. Removing the app clears the Keystore key, so an uninstall/reinstall cannot be treated as an authenticated session. The new install offers username/password or the linked Google/LinkedIn account to recover the same account ID and synced records. Sign-out and remote session revocation still invalidate the server session.

Android backups and cable transfers exclude `ca_progress_secure_session.xml` on both pre-Android-12 and Android-12+ rules. If a prior build backed up that encrypted file, the secure-session plugin discards it when its key cannot decrypt it and shows login instead of blocking app launch. Backup availability itself depends on Android/user backup settings; offline-only records cannot be promised after uninstall. Only cloud-synced records return after sign-in.

For test fixtures, `node scripts/auth/create-test-account.mjs --username tester_name --display-name 'Tester'` provisions a password account in local D1. Set `CA_TEST_ACCOUNT_PASSWORD` through a secret environment input of 12–128 characters. `--remote` explicitly targets the production-bound D1 configured in `wrangler.jsonc` and needs Cloudflare credentials; use only for an intentionally created test user. The tool generates a random new user ID, uses the same PBKDF2 parameters as production login, checks username availability, and verifies the three account rows. It does not create a provider identity or expose a public registration endpoint. The resulting account can log in via username/password and remains distinguishable by `auth_provider='manual-test'`.

Testing: upgrade over existing app (session remains), uninstall and reinstall (login required), sign in to the existing user ID (cloud data returns), remote revoke (old token fails), and test-account login on web/Android. These end-to-end device/provider checks require an installed Android device and credentials; code checks alone cannot certify them.
