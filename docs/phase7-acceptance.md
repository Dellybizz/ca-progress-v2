# Phase 7 acceptance mapping

1. **Private files cannot be fetched by another user through a guessed URL.** File bytes live in the private Cloudflare R2 bucket `ca-progress-v2-staging-user-resources`. The bucket has no public URL. `/api/resources/[id]/access` authorizes the signed-in user against Supabase metadata first, then the Worker streams the R2 object only to the owner or to an authenticated user when the resource is shared and moderator-approved.
2. **Upload validation occurs server-side.** `/api/resources/upload` verifies authentication, content length, maximum file size, extension, exact MIME mapping, file signature/magic bytes, and safe filename normalization before writing the bytes through the private `USER_RESOURCES_R2` Worker binding. Metadata is then committed through an authenticated security-definer Supabase RPC; an R2 object is deleted again if metadata persistence fails.
3. **Shared resources require moderation.** Database triggers force new or materially edited shared notes/uploads to `pending`; RLS exposes only `approved` shared rows. Authorized moderator/admin/owner roles decide through the moderation RPC. Reports change an approved item to `reported`, hiding it until review.
4. **ICAI resources are visually distinct from user uploads.** The unified library renders Phase 8 official resources with a dedicated ICAI card class, shield icon, green official styling and `ICAI Official` / `Official · Verified` badges.
