# Notes Phase 3 — configurable CA workings

Formats now retain their identity, variant, title, periods, currency, number styles, borders and density in the structured note. Tables remain ordinary editable Tiptap cells; stable row/column IDs preserve values when renaming or reordering. Native row/column additions gain identities without rebuilding the document. Existing ordinary tables can adopt format controls without replacing their contents.

Priority layouts include vertical/horizontal/comparative statements, journal entry types, ledger T-accounts/running balances, trial balance adjustments, single/double/triple cash books, direct/indirect cash-flow starting rows and total/per-unit/comparative cost sheets. The catalogue supplies editable study structures, not automatic statutory computations. Different accounting structures can be inserted as a blank variant alongside the original. Reconfiguration refuses to remove populated columns; merged tables must be unmerged before changing their structure.

Numeric columns support Indian/western/no grouping, 0–6 displayed decimals, negative brackets/minus signs, zero/dash, alignment and tabular digits. Canonical decimal values retain precision when display precision changes. Typed values format when leaving a cell; narration stays editable and invalid numeric text remains untouched. Read-only HTML/PDF rendering applies the same numeric settings even to a save made before blur. Header/cell marks and existing paragraph identities are retained where formatting changes text.

Totals are explicit signed sums over chosen rows and numeric columns. The engine uses scaled BigInt decimal arithmetic, never JavaScript evaluation or binary floating-point summation. References use stable identities. Source edits mark totals stale; the user recalculates, edits sources, or keeps existing results as manual values. Circular/missing references and invalid amounts refuse calculation with the source content retained. Source definitions and calculation baselines persist with the note. Blank copies retain labels/structure/calculations while clearing entered amounts, dates, references and other non-label cells.

The compact inspector separates Setup, Structure, Numbers and Totals, includes a live table preview, and keeps Apply/Cancel outside scrolling fields. Mobile preview is collapsible. Structural/configuration application, calculation updates and blank-copy insertion create isolated undo steps. Blank-copy insertion leaves the caret after the new format. Resources, existing permissions, revision guards and offline recovery remain the persistence path; no database migration is needed.

Limits: 200 body rows and 12 columns per working, 80 source terms per total, six decimal places, bounded note/model size and amount range. This release does not provide general spreadsheet formulas, automatic tax computation or statutory filing certification. Ink/annotation and broader physical-device/export certification remain their planned phases.

Validation covers journal exercises, exact signed totals, retained precision/marks/identities, compatible variant changes, safe refusal of destructive changes, schema/security bounds, actual API/D1 JSON round trips, native row/column edits, totals editing/recalculation/undo, blank reuse, offline recovery, old notes, six screen widths, charts/images and A4 portrait/landscape exports. Final release evidence is recorded separately after deployment succeeds.
