# Phase R1 — Core desktop and mobile wireflows

These are structural wireflows, not high-fidelity page designs. They lock order, navigation and disclosure before route styling begins.

## Daily study loop

| Mode | Flow |
| --- | --- |
| Desktop | Shell → Dashboard: next action + exam/ICAI context → Today Plan: anchored timeline → Study: timer + academic context → Reflection → Progress confirmation |
| Mobile | Home: one next action → Today: next anchored item → Study full-screen → compact reflection sheet → Progress subject summary |

Mobile defers leaderboard detail, extended analytics and older ICAI items. They remain reachable from Activity, Analytics and Updates.

## Plan and reschedule

| Mode | Flow |
| --- | --- |
| Desktop | Planner analytics strip → quick add → task list → schedule/calendar detail → edit panel → recalculated Today Plan |
| Mobile | Planner summary → Add task full-screen flow → Today’s tasks → task detail sheet → Today Plan/Calendar → recalculated order preserving fixed times |

## Learn and record

| Mode | Flow |
| --- | --- |
| Desktop | Syllabus/subject → Chapter Hub → Study or resource → Notes side/supporting region → save → chapter state |
| Mobile | Syllabus list → chapter detail → choose Study, Resource or Notes → one full-screen workspace → return with position and context preserved |

## Find trusted content

| Mode | Flow |
| --- | --- |
| Desktop | Resource surface → visible academic/provenance filters → result list → preview/detail → signed/open action |
| Mobile | Resource list → filter sheet → labelled result summaries → full detail → open/download; filter and scroll state survive return |

## Community participation

| Mode | Flow |
| --- | --- |
| Desktop | Community/channel list → selected conversation → contextual details/actions |
| Mobile | Community channel list → full-screen conversation → message action sheet or channel details → back to preserved list position |

## Account and billing

| Mode | Flow |
| --- | --- |
| Desktop | Settings index → concern section → edit/confirm panel → success state |
| Mobile | Settings list → focused concern page → bottom-sheet confirmation when simple or full-screen flow when complex → return with updated summary |

## Admin operation

| Mode | Flow |
| --- | --- |
| Desktop | Admin attention summary → filtered table/list → side detail → authorized action → receipt/audit link |
| Mobile | Admin priority list → filter sheet → labelled record summary → full-screen detail → sticky authorized action → result and audit evidence |

Across all flows: Escape/outside click applies to desktop overlays; mobile uses sheets/full screens with explicit close/back; loading, empty, stale, offline, permission and error states preserve the user’s context and next safe action.
