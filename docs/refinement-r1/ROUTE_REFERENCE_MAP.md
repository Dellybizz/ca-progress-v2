# Phase R1 — Route-to-reference map

| Surface | Single page purpose | Primary reference | Secondary evidence | Explicit boundary |
| --- | --- | --- | --- | --- |
| `/dashboard` | Decide what to do now and see urgent CA context | Amie | Quizlet for learning state | Not a complete analytics, planner or leaderboard page |
| `/planner/today` | Execute today’s time-aware study plan | Todoist | Amie for scheduled anchors | Not the full calendar or planning dashboard |
| `/planner`, `/calendar`, `/goals` | Plan future work and commitments | Todoist | Amie for calendar hierarchy | Preserve academic context and fixed-time anchors |
| `/study` | Run and complete the current study session | Quizlet | Goodnotes for focus discipline | No mini-dashboard or decorative metrics |
| `/progress`, subject progress | Understand syllabus completion and next gap | Quizlet | Dub for summary metrics | No unrelated activity leaderboard |
| `/analytics`, `/analytics/forecast` | Explain patterns and forward risk | Dub | Linear for filters | Charts require textual meaning; no decorative metrics |
| `/tests` | Record and review private test attempts | Quizlet | Linear for archive rows | Not a test provider or quiz-generation surface |
| `/notes`, `/notes/[id]` | Find or edit chapter-linked notes | Goodnotes | Linear for note list/search | Mobile list and editor are separate focused modes |
| `/resources`, `/resources/icai` | Find trusted material and open it | Linear | Quizlet for academic grouping | Community and official ICAI provenance remain distinct |
| `/updates` | Review relevant official ICAI changes | Linear | Quizlet for educational language | Not a generic notification feed |
| `/community`, channel | Discover a channel or participate in one conversation | Linear | Quizlet for learner identity | Channel list and active conversation must not compete on phone |
| `/study-buddy`, `/activity` | Manage accountability or review earned activity | Quizlet | Linear for lists | Gamification never dominates core study navigation |
| `/settings`, `/billing`, `/pricing` | Manage one account concern at a time | Linear | Amie for calm hierarchy | No promotional dashboard inside settings |
| `/admin/**` | Inspect state and complete an authorized operation | Linear | Dub for operational summaries | Student decoration and tiny desktop-only controls are prohibited |
| `/login`, `/onboarding` | Enter the product or establish canonical study context | Quizlet | Amie for restraint | One decision per step; no feature-tour clutter |

The existing desktop primary destinations and mobile `Home / Today / Study / Progress / More` contract remain canonical. Later phases may change composition, not route ownership or authorization boundaries.
